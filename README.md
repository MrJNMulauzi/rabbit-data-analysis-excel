
# Rabbit Population Data Analysis (Excel)

## Overview
This project demonstrates basic data analysis using Microsoft Excel. The dataset contains rabbit population records, which were cleaned, structured, and analysed to extract meaningful insights.

## Objectives
- Clean and structure raw CSV data
- Calculate key metrics (e.g., average age)
- Apply conditional logic to classify data
- Explore patterns within the dataset

## Tools Used
- Microsoft Excel

## Key Tasks Performed
- Imported and formatted CSV data into structured columns
- Calculated average age using Excel formulas
- Used IF statements to classify rabbits as "Younger" or "Older"
- Analysed trends in the dataset

## Outcome
This project helped build foundational skills in data cleaning, analysis, and basic reporting using Excel.
